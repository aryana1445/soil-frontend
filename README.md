# Soil Nutrient Analysis and Fertilizer Recommendation System - Frontend

A comprehensive React-based frontend application for analyzing soil nutrients and providing crop-specific fertilizer recommendations.

## Project Overview

This frontend application is part of the Department of Information Science & Engineering's Project Phase-I (22ISE65). It provides farmers with an accessible, affordable web/mobile interface to:

- Input soil nutrient parameters (N, P, K, pH, moisture)
- Analyze soil health status
- Receive crop-specific fertilizer recommendations
- Track analysis history
- Access agricultural resources

## Features

- 📊 Interactive soil nutrient dashboard with visualizations
- 🌾 Support for 22+ crop types
- 📋 Detailed fertilizer recommendations with dosage calculations
- 📈 Analysis history and comparison tools
- 📱 Fully responsive mobile-friendly design
- 🌙 Dark mode support
- 📤 Export results as PDF/CSV
- 🎓 Educational resources and best practices
- ♿ Accessibility features (WCAG compliant)

## Tech Stack

- **React 18** with TypeScript
- **Tailwind CSS** for styling
- **Recharts** for data visualization
- **React Hook Form** for form management
- **Context API** for state management

## Getting Started

### Prerequisites

- Node.js 16+ 
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/aryana1445/soil-frontend.git
cd soil-frontend

# Install dependencies
npm install

# Start development server
npm start

# Build for production
npm run build
```
